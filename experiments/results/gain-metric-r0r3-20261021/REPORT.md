# R0~R3 첫 시도 이득 G 재평가 (2026-10-21)

R0~R3 비교 실험의 모델과 저장된 점수를 그대로 쓰고, 비교 지표만 첫 시도 이득 G로 바꿨다. 재학습·GPU·새 LLM 호출은 없다. 같은 점수 파일과 같은 튜닝/평가 분리를 쓴 [λ 정밀 탐색](../lambda-sweep-20261002/REPORT.md)과 비교하면 정답 기준(quality → 첫 시도 success), 비용(데이터 실제 비용 → 1:3:5), 고르는 기준(예산·유지율 → G)이 다르다.

## 1. 결론

- **A 실험(봉인 test):** 모델 출력 그대로(λ = 0) G는 R0 −.004 [−.010, +.002], R1 +.020 [+.017, +.024], R2 +.022 [+.018, +.026]이다. R1·R2는 R0보다 분명히 낫고(짝지은 차이 구간이 0을 포함하지 않음), R1과 R2는 구분되지 않는다.
- **G1 selection:** R1·R3 네 가지 모두 0 근처(−.008~+.010)이고 서로 구분되지 않는다.
- **G1 task holdout:** 모두 기준선보다 낮다(R1 −.11~−.12, R3 −.09~−.10). 이 데이터의 xRouteBench에서는 high가 low·medium보다 못해(첫 시도 성공 .498 대 low .703·medium .735), 기준선이 더 싸고 더 잘 푸는 혼합으로 잡히고 high를 많이 쓴 라우터가 손해를 본다.

## 2. 무엇을 했나

| 항목 | 내용 |
|---|---|
| 지표 | G = A − H(C). A = 고른 단계의 첫 시도 성공(`success`, 0/1), C = 평균 단계 가격(1:3:5, high = 1), H(C) = 비용 C 이하에서 고정 단계 세 점과 그 혼합이 낼 수 있는 최고 첫 시도 성공(위로 볼록한 껍질, 최고점 뒤는 평평). EV-10 11_gain과 같은 정의 |
| 대상 | A(RT-05): R0(CE)·R1(성공 BCE)·R2(pairwise), 튜닝 D_dev, 평가 봉인 test. G1(RT-06): R1·R3 × natural·balanced, 튜닝 calibration, 평가 selection·task holdout |
| 운영점 | `lambda0`: 모델 출력 그대로 `argmax(score)`. `gmax`: 결정 규칙 `argmax(score − λ × 단계 가격)`의 λ를 0과 10⁻⁴~10² 로그 601점에서 훑어 튜닝 데이터 G가 가장 큰 값을 원천마다 고르고 평가 데이터에 그대로 적용. λ는 결정 규칙의 하이퍼파라미터이고 지표에는 들어가지 않는다 |
| 집계 | 원천별 계산 후 두 원천 같은 비중 평균. 문항 bootstrap 2,000회(seed 20261021), 같은 실험·데이터의 라우터는 같은 재표집을 공유(짝지은 차이) |
| 참고 | oracle = 맞히는 가장 싼 단계(아무도 못 맞히면 low) |
| 실행 | `ml/notebooks/routing_objective_comparison/08_gain_metric.ipynb`, Colab과 로컬 결과가 같다(25행, G 차이 0). 입력 21개는 λ 정밀 탐색 manifest의 SHA-256과 일치(`manifest.json`) |

## 4. 해석과 한계

- **R0는 λ = 0에서 이미 싼 쪽(C .37)에 있고 기준선과 구분되지 않는다.** λ로는 더 싼 쪽으로만 움직여 G를 올릴 여지가 없다. R1·R2는 비용을 보지 않고 성공 가능성이 큰 단계를 고르는 출력이라 λ = 0에서 비싼 쪽(C .84~.85)에 몰리지만, G는 그 비용의 기준선과 비교하므로 공정하게 비교된다.
- **R3는 A 실험에 없다.** R3는 G1에서만 학습돼 R0·R2와 같은 표에서 직접 비교되지 않는다. R3는 학습 목표에 λ grid가 들어간 방법이라, 지표가 λ를 쓰지 않아도 추론 λ = 0의 R3는 이미 비용을 고려한 결정이다.
- **대표 모델 기준이다.** 단계는 원천마다 대표 모델 하나이고, EV-10(모델 집단 기준)의 G와는 단계 정의가 달라 직접 비교하지 않는다.
- 단일 seed, v1 채점 데이터. 구간은 문항 표본의 흔들림만 반영한다.

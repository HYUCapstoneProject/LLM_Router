# F4 양방향 오류 교정 재학습 결과 — 2026-10-10

실험 코드: **RF-03** · [실험 목록](../../REGISTRY.md)

[계획서 14절](../../../docs/ml/RETRAINING_EFFECT_EXPERIMENT.md)의 F4를 개인 Colab T4에서 실행한 결과다. 운영 1.0(F0)이 stream에서 원래 난이도 라벨보다 **높게 또는 낮게** 예측한 질문을 모두 골라 원래 라벨로 6번 재학습하고(seed 42/43/44), F2와 같은 복습을 섞었다. 최종 평가는 봉인 test 7,202문항과 RouterArena 8,379문항, 8192 토큰이다. 라벨과 라우팅 결과는 v1 채점 기준이다.

## 1. 결론

1. **재학습 후 난이도 판단 성능은 크게 떨어졌다.** test 정확도 .619→.278, RouterArena .454→.244. seed 세 개가 거의 같다(test .274~.281).
2. **판단이 medium 쪽으로 옮겨 갔다.** easy 예측이 64.5%→12.3%, 원래보다 높게 예측한 비율이 .113→.561이다. hard 재현율은 .276→.357로 조금 올랐다.
3. **라우팅 첫 시도 품질은 올랐지만 "항상 medium"을 넘지 못했다.** RouterBench에서는 항상 medium과 품질이 같고 상대 비용이 약 5배다. xRouteBench에서만 혼합선을 +.009 넘었다.
4. **원인은 학습 데이터의 라벨 비율이다.** 운영 1.0은 원래보다 낮게 틀린 경우가 높게 틀린 경우의 2.2배(1,451 vs 663)였다. 그래서 오답만 모으면 easy 27%·medium 49%·hard 24%가 된다(실제 stream은 49/38/13%). 정답 라벨로 배워도 비율이 바뀌면 판단 기준이 따라 움직인다. 초기 학습 복습 96행은 1,000행 넘는 오답 데이터를 되돌리지 못했다.
5. 운영 설정·`CURRENT`는 바꾸지 않는다. 비율을 실제 분포에 맞춘 대조 실험을 F5로 설계했다(계획서 15절).

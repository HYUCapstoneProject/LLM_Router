## 1. 결론과 상태

**exact 캐시(C1)는 잘못된 재사용 없이 반복 비율만큼 호출을 줄였다. 의미 캐시(C2, 운영 C3)는 exact보다 호출을 조금 더 줄이는 대신 다른 질문의 답을 돌려주었다.** D2의 함정 질문(문장은 거의 같고 정답이 다른 질문)은 운영 C3에서 test 기준 72%가 hit됐다. calibration 격자 3,127개 설정 중 "hit 중 잘못된 재사용 ≤ 1%"를 만족한 설정은 없었다. 사전 규칙에 따라 보정 정책은 exact-only로 봉인했다.

## 2. 데이터

- **pool**: 연속학습 stream 5,368문항 중 서비스 입력 한도(BGE 512토큰)를 넘는 33문항을 제외해 5,335문항이다(RouterBench 4,670 / xRouteBench 665). 각 문항에 운영 R0 라우터가 고른 단계 모델의 **기록 답변·정답 여부·비용**을 붙였다. LLM은 새로 호출하지 않았다. RouterBench 답변은 stream 점수와 행 단위로 일치하는 5-shot pkl에서 가져왔다.
- **D1**: D2 원질문을 뺀 5,035문항으로 요청 4,000개 trace를 만들었다. 반복 비율 0/10/30/50% × seed 3개(20260930~32)다. 같은 (비율, seed)에서는 모든 비교군이 같은 trace 파일을 재생한다.
- **D2**: 원질문 300그룹(calibration 100 / test 200)마다 같은 뜻 변형 1개와 함정 변형 1개를 만들었다. 층별 원질문 수는 rb_mcq 129, rb_math 51, rb_open 21, xrb_mcq 51, xrb_numeric 27, xrb_open 21이다.
  - **변형 작성**: Claude 초안을 외부 리뷰 2회로 고쳤다(`manifests/variants-manifest.json`).
  - **판정**: 외부 LLM 사전평가 1개(`annotation_mode=single_llm`)를 썼다. 사람 2명의 독립 판정이 아니다. 판정 모델은 기록되지 않았고 사람이 검수하지 않았다. 같은 내용으로 다시 제출된 파일은 중복으로만 기록했다(`manifests/dataset-manifest.json`).
  - **품질 표시**: 출처 이상 1그룹(d2-055)과 낮은 품질의 함정 1그룹(d2-114)에 표시를 붙였다. 둘을 빼고 계산한 값도 함께 보고한다.
- **입력 SHA**: `manifests/prepare-manifest.json`에 7개 입력의 경로와 SHA-256이 있다.

### 4.2 D2: 보정과 test (LLM 판정 기준)

## 5. 분석과 다음 결정

1. **관측**
   - exact 캐시는 오재사용 0으로 반복 비율만큼 절감했다.
   - 운영 C3를 r30에서 C1과 비교하면 호출 절감은 2.0pp 늘었다. 대신 hit 중 8.3%가 다른 질문의 답이었고, 보수 품질은 −1.5pp였다.
   - C2는 절감이 11.6pp 늘고 보수 품질이 −9.5pp였다.
   - D2 test에서 C2·C3의 95% 상한은 각각 54.8%와 51.0%다. 계획서 8절의 5% 기준을 크게 넘으므로 **"해당 설정의 semantic 재사용은 안전성 근거 부족"**으로 기록한다.
2. **해석(가설)**
   - 현재 BGE 코사인과 quora 리랭커는 "표면이 거의 같고 조건 하나가 다른 질문"을 같은 질문으로 본다.
   - 임계값을 올리면 같은 뜻 질문을 먼저 잃는다. 그래서 임계값 조정만으로 해결되지 않는다.
   - 시간·순서·출력 형식처럼 짧은 표현 차이의 함정이 특히 잘 통과했다.
3. **한계**
   - **D2 라벨·변형**: 변형도 LLM이 쓰고(리뷰 2회) 판정도 LLM 1개가 했다. 오류가 같은 방향으로 겹칠 수 있다. D2 수치는 LLM 판정 기준 추정치이며 사람이 검증한 안전성이 아니다.
   - **D2의 성격**: 함정 50%를 섞은 스트레스 세트다. hit 중 잘못된 재사용 비율은 실제 트래픽의 비율이 아니다.
   - **D1의 반복 비율**: 관측된 서비스 비율이 아니라 민감도 조건이다. 생성 답변은 기록 outcome을 재생한 것이므로, 같은 질문을 다시 생성할 때의 답변 변동성은 측정하지 않았다.
   - **512토큰 제외**: 33문항을 제외했다. 제외 당시 근거는 서비스의 512 거절이었다. 이 거절은 2026-10-02 PR #52로 되돌려졌다. 따라서 현재 main 기준으로는 512 초과 질문이 잘린 임베딩으로 캐시를 탄다. "앞 512토큰은 같고 뒤만 다른" 위험은 이번 실험에서 측정하지 않았다.
   - **지연**: Mac 2 스레드에서 잰 값이며 운영 VM과 같다고 주장하지 않는다. end-to-end 지연은 가정 기반 시뮬레이션이다.
   - **라우터 입력 차이**: 서비스 입력(`query_text`)과 로거 입력(`model_input_text`)의 라우팅 일치는 86.5%다. 이번 실험은 서비스 입력으로 라우팅했다. 학습·서빙 입력 차이는 별도 과제다.
4. **다음 결정 후보** (팀 결정. 이 보고서가 운영을 바꾸지 않는다)
   - 운영 semantic 캐시(C3)를 끄고 exact만 쓰는 방안을 검토한다.
   - 의미 캐시를 유지하려면 다음이 필요하다.
     - 질문 유형별 비활성화나 조건 추출 같은 다른 판별 신호
     - 사람이 판정한 D2
     - 새 calibration과 새 run
   - 이번 test는 이미 사용했으므로 이 결과를 보고 임계값을 다시 조정하지 않는다.

### 7.3. 원인 점검

**질문 1. BGE 512토큰 한계를 넘어 뜻이 잘린 것인가? → 아니다.**
- BGE 토큰 수
  - D2 원질문 300개: 최대 501
  - 변형 600개: 최대 505, 중간값 93
  - 512 초과: 0개. 임베딩은 모든 문장을 끝까지 읽었다.
- 리랭커는 두 질문을 **이어 붙여 한 입력으로** 읽는다. 운영 서빙도 합친 길이 512에서 자른다.
  - D2 600쌍 중 88쌍(15%)이 512를 넘었다. rb_mcq 60, xrb_mcq 22, xrb_open 6이다.
  - 바뀐 부분이 잘려 보이지 않게 된 함정은 300개 중 5개다(한쪽 4, 양쪽 1). 289개는 바뀐 부분이 그대로 보였다.
- calibration 함정의 운영 C3 통과율은 잘리지 않은 쌍 79.5%(88쌍), 잘린 쌍 50%(12쌍)였다. 잘림이 통과를 늘리지 않았다.

**질문 2. 질문이 길어 바뀐 비중이 작기 때문인가? → 비중 차이는 크지만, 그것만으로는 설명되지 않는다.**
- 바뀐 비중의 정의: 바뀐 리랭커 토큰 수 / 두 질문 중 긴 쪽의 토큰 수.

| | 바뀐 토큰 (중간값) | 바뀐 비중 (중간값, 사분위) |
|---|---:|---|
| 8월 함정 | 7 | 50% (28~73%) |
| D2 함정 | 10.5 | 11% (5~18%) |
| 8월 같은 뜻 | 10 | 83% |
| D2 같은 뜻 | 13 | 13% |

- 바뀐 토큰 수는 비슷하고 질문 길이가 약 8배 달라서, 비중이 약 4.5배 차이 난다. D2는 같은 뜻 질문도 13%만 바꿨다. D2 전체가 거의 같은 문장끼리의 비교였다.
- 그러나 **바뀐 비중이 같은 구간끼리 비교해도** 통과율 차이가 남는다.

| 바뀐 비중 | 8월 통과율 | D2 통과율 |
|---|---|---|
| 5% 이하 | — | 81% (27) |
| 5~10% | 0% (2) | 73% (22) |
| 10~20% | 0% (6) | 74% (34) |
| 20~40% | 29% (7) | 79% (14) |
| 40% 초과 | 0% (22) | 67% (3) |

  - 겹치는 구간의 8월 표본이 2~7쌍으로 작다. 그래서 "비중은 영향이 없다"고 결론 내리지는 않는다.

**남은 후보 (아직 분리하지 않음)**
1. 절대 길이: 긴 두 문장이 대부분 같으면 같은 질문으로 보는 경향
2. 글의 종류: HellaSwag 지문, 객관식 선택지, 수학 문장제처럼 Quora 학습 데이터와 다른 형식
3. 함정 작성 방식: D2 변형은 LLM이 썼다

### 7.4. 해석에 미치는 영향

- 8월의 enforce 결정 근거(오탐 19건 → 1건)는 짧은 질문 조건의 결과다. 이 run은 그 결론이 긴 벤치마크형 질문으로 일반화되지 않음을 보였다.

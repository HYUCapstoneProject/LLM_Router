# R0·R1·R2 난이도·라우팅 진단

[통합 시각화](index.html) · [RouterArena 상세](routerarena/index.html) · [실험 기록](run.json)

검증 3,581문항과 RouterArena full 8,379문항을 비교했다. 변형 412개는 full과 짝지어진 질문이므로 독립 표본 수에 더하지 않는다.

## 핵심 결과

- Medium은 세 모델 모두에서 선택된다. 다만 dev RouterBench R2의 medium 선택은 88.02%, xRouteBench R0는 6.32%로 출처별 편중이 크다.
- xRouteBench R0 정확도 72.11%는 train의 출처·카테고리 다수 라벨 기준선 71.46%와 가깝다. 전체 R0가 shortcut만 사용한다는 인과 증거는 아니다.
- 카테고리 내 선택 셔플보다 R1/R2의 RouterBench 품질은 높았지만 비용도 높았다. xRouteBench에서는 세 방법 모두 셔플 품질의 중앙 95% 범위 안이었다. 사후 dev 진단이며 신뢰구간이나 동일비용 검정이 아니다.
- RouterArena R0 정확도 45.48%, macro-F1 0.3961, hard→easy 52.34%, hard recall 15.02%. Always-easy 정확도는 47.49%다. 정확도만으로는 이 단순 기준선을 넘지 못하지만 macro-F1는 더 높다.
- Arena λ=0 medium 선택률은 R0/R1/R2 38.78%/10.65%/25.16%, high 선택률은 10.38%/86.84%/69.05%다. R1/R2는 난이도 분류기가 아니므로 이 투영을 실제 후보 성공률이나 운영 성능으로 읽지 않는다.
- 512토큰 초과는 748/8,379(8.93%). 변형 후 같은 선택 유지율은 54.37%/79.85%/62.86%이며, 한 행동에 집중하면 유지율도 높아질 수 있다.

## 해석과 다음 판단

현재 결과로 일반적인 난이도를 충분히 학습했다고 확정할 수 없다. 기존 D_dev 기준 R1 선정은 유지하지만 서비스 모델 풀에서의 성공률·비용 평가와 재학습 승격 근거를 대신하지 않는다. 다음 실험은 출처·카테고리 미관측 분할, 같은 후보 풀의 성능 라벨, 동일비용 기준선을 사전에 정해야 한다. 이번 Arena 결과로 임계값이나 승자를 다시 최적화하지 않았다.

T1은 정답률 기반 난이도이고 Arena는 공식 Difficulty다. 둘의 정확도를 같은 과제의 성능 하락으로 직접 해석하지 않는다. 과거 Arena 관측이 있으므로 완전히 처음 보는 blind test도 아니다.

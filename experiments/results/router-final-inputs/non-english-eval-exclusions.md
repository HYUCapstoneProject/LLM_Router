# 영어가 아닌 평가 문항 제외 목록 (EV-10)

작성일: 2026-10-17. 파일: [non-english-eval-exclusions.csv](non-english-eval-exclusions.csv) (sample_id와 출처만 담았고 질문 원문은 없다).

## 왜

서비스와 서비스의 BGE(bge-large-en-v1.5)는 영어 질문만 받는다. 그래서 평가(dev·test·RouterArena 진단)도 영어 문항만 쓴다(사용자 결정, 10-17). 학습 행(35,176)을 아래 규칙 1·3·4로 보면 요청 자체가 영어가 아닌 문항은 없다. 영어 지시에 외국어 지문이 붙은 문항이 3건 있다(LLMRouterBench HLE의 러시아어·히브리어 지문 2건, RouterBench 번역 요청 1건). 평가였다면 뺄 문항이지만, 사용자 결정에 따라 학습은 다시 하지 않는다.

## 결과

| 원천 | 역할 | 제외 |
|---|---|---:|
| LLMRouterBench | test (arenahard, `judge_preference_diagnostic`) | 246 / 740 |
| LLMRouterBench | dev | 0 |
| RouterBench · xRouteBench · SPROUT | dev · test | 0 |
| RouterArena | 진단 | 0 |

LLMRouterBench test는 4,260행에서 4,014행이 된다. dev에는 영어가 아닌 문항이 없어 07b의 설정 선택과 λ는 바뀌지 않는다(로컬 시험 실행에서 방법별 dev 이득이 소수점 다섯째 자리까지 같았다).

`dominant_script`는 글자 수로 센 주 문자다. 코드가 길면 질문이 중국어·러시아어여도 `latin`으로 나온다.

## 방법

평가 행 전체(dev 7,828 · test 18,353 · RouterArena 8,400)에 가벼운 규칙 네 가지를 적용해 후보를 모은 뒤, 후보를 모두 사람이 읽어 판정했다. 언어 판별 모델은 쓰지 않았다.

1. 주 문자가 라틴 문자가 아님(한자·키릴·가나·한글·아랍·그리스·태국·히브리)
2. 코드 블록과 수식을 뺀 단어 중 영어 기능어(the, of, and, is 등) 비율 < 6%
3. 비라틴 문자 3자 이상
4. 스페인어·프랑스어·독일어·이탈리아어·포르투갈어·베트남어·인도네시아어·체코어·폴란드어 기능어 비율 ≥ 12%이고 영어 기능어보다 많음
5. 확인용: 위에 걸리지 않은 행 중 라틴 확장 문자(악센트)가 많은 행

판정 기준:

- **뺀다:** 요청이 영어가 아님. 코드나 로그가 붙어 있어도 요청 문장이 중국어·러시아어·한국어 등이면 뺀다. 영어 지문에 영어가 아닌 지시가 붙은 것, 지문 주요 부분이 영어가 아닌 것(예: 아랍어 시 + 영어 지시)도 뺀다.
- **남긴다:** 영어 질문에 외국어 고유명사·단어·제목이 들어간 것(예: HLE의 고대 러시아어 접어 목록, 중국 시인 이름, SimpleQA의 악센트 있는 지명), 영어 문제에 한국어 머리말(문제·입력·출력)만 붙은 것, 언어가 없는 수식·숫자 퍼즐·체스 기보.

영어로 판정해 남긴 경계 사례(arenahard): 27, 39, 44, 81, 107, 115, 144, 154, 178, 188, 202, 219, 223, 277, 287, 289, 306, 365, 368, 395, 409, 417, 420, 625, 634, 696, 718, 750 (`llmrouterbench:arenahard:<번호>`).

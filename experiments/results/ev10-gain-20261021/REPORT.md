# EV-10 첫 시도 이득 G 재평가 (2026-10-21)

EV-10 라우터 비교를 효용 U 대신 첫 시도 이득 G로 다시 평가했다. **학습은 다시 하지 않았다.** 04~07a가 저장한 모든 설정의 점수와 09의 seed 보정을 그대로 썼고, 원래 EV-10 결과([REPORT.md](../ev10-router-final-20261018/REPORT.md))는 바꾸지 않았다.

## 1. 결론

- 원천 4개 평균 G(τ = .8 규칙)는 모든 라우터가 0보다 크지만 작다. 1위 kNN +.024 [+.021, +.027], R1-집단 +.022, R0-집단 +.021, IRT-Router +.020이다. 정답 풀 확률로 고른 `needed_tier`(참고)는 +.169다.
- 상위권은 서로 거의 구분되지 않는다. kNN·R1-집단·R0-집단·IRT 사이는 대부분 95% 구간이 0을 포함하고, kNN − R0-집단(+.004)만 구분된다.
- U 기준과 순위가 다르다. U에서 1위였던 GraphRouter(+.044)는 G에서 +.018로 중위권이고, U에서 R1-집단보다 뒤였던 R0-집단은 G에서 R1-집단과 구분되지 않는다.
- 풀리는 문항(solvable 층) 안에서 G는 대부분 양수(+.003~+.021)다. U에서는 이 층의 이득이 모두 0 이하였다. 첫 시도 기준으로는 작지만 난이도를 가르는 능력이 보인다.
- 집단 평균 가격으로 바꾸면 모든 이득이 +.014 이하로 줄고 일부는 음수다(U와 같은 양상).

## 2. 무엇을 했나

| 항목 | 내용 |
|---|---|
| 지표 | G = A − H(C). A = 시작 단계의 첫 시도 성공(집단 풀 확률 평균), C = 첫 시도 비용 평균(Claude 1:3:5, .2/.6/1.0), H(C) = 첫 시도 비용 C 이하에서 고정 시작 단계(혼합 포함)가 낼 수 있는 가장 좋은 첫 시도 성공. λ·κ·상향은 G에 없다 |
| 보정 | 07b와 같은 원천·단계별 isotonic 어댑터, 같은 5분할 교차 보정. 07b와 같은 설정은 07b 보정을 정확히 재현함을 확인(차이 > 1e-9면 멈춤) |
| 설정 선택 (dev) | 방법마다 τ = .8 규칙의 dev G(원천 4개 평균) 최대. 07b(U 기준)와 다른 설정: Avengers-Pro, GraphRouter(1000 → 100 epoch), Hybrid LLM, IRT-Router(λ 0 → .3), kNN-A, MF, MLP, RouterDC, R1-BGE. 후보 간 dev G 차이는 대부분 작다([gain-lock-summary.md](gain-lock-summary.md)) |
| 결정 규칙 | 주 결과 τ = .8(보정 확률 ≥ .8인 가장 싼 단계), τ .5~.95 곡선, 한 번에 고르기 `argmax(p̂ − λ × 가격)`의 비용 수준 25·50·75%(첫 시도 비용 .4/.6/.8, λ는 dev에서 맞춤) |
| 평가 | 08과 같은 test 행(17,662문항, 영어가 아닌 문항·문서 제공형 제외), 질문 묶음 단위 paired bootstrap 10,000회(08과 같은 표본) |
| 참고 행 | `needed_tier`, 운영 R0·RT-08(A 분할, 07b 보정). 순위에 넣지 않는다 |
| 제외 | R1-BGE는 lock에는 남기고 결과 표에서 뺐다(2026-10-21 사용자 결정) |
| 실행 | 2026-10-21 Colab CPU, `ml/notebooks/router_final/11_gain.ipynb`·`gain_eval.py`. lock은 dev만 읽었고, test는 lock 확인 뒤 한 번 열었다(102초) |

## 4. 해석과 한계

- **G와 U는 다른 질문에 답한다.** U(κ\*)는 "상향이 있는 서비스에서 라우터가 이득인가", G는 "첫 시도에서 단계를 잘 고르는가"다. 가망 없는 문항에서는 G가 싼 단계를, U는 처음부터 비싼 단계를 보상한다. G는 U 결과를 대체하지 않는다.
- **사후 지표다.** G는 원래 EV-10 test를 연 뒤 정한 지표다. 다만 운영점과 설정은 dev에서만 고르고 test에는 적용만 했다.
- **단계 비용 1:3:5는 가정이다.** 집단 가격 민감도에서 순위가 바뀐다(예: kNN-A가 1위).
- 단일 seed(H5 두 모델만 seed 3개). 구간은 문항 표본의 흔들림만 반영한다.
